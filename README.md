## No que venho me especializando

- **C# e EF Core:** Desenvolvimento no ecossistema .NET, aplicando mapeamento objeto-relacional (ORM) para consultas eficientes, seguras e manipulação de dados.
- **Node.js:** Construção de APIs RESTful estruturadas, assíncronas e de alta performance utilizando JavaScript.
- **Java:** Fortalecendo conceitos de Programação Orientada a Objetos (POO) e arquitetura de software estável.
- **Bancos de Dados Modernos:** Modelagem em PostgreSQL para dados relacionais e uso estratégico do Firebase Realtime Database para aplicações que exigem sincronização instantânea em nuvem.
